# 🌡️ Temperature Prediction Using Simple Linear Regression

## 📌 Project Overview
This project demonstrates how to build a **Simple Linear Regression** model to predict **Temperature** based on **Humidity**. It covers the complete machine learning workflow, including data loading, preprocessing, model training, evaluation, and visualization.

This project was completed as part of a **Data Science Internship**.

---

## 🎯 Objective
- Predict temperature using humidity values.
- Understand the relationship between humidity and temperature.
- Learn the implementation of Simple Linear Regression using Scikit-learn.

---

## 📂 Dataset
The dataset contains weather-related information with the following features:

- **Humidity** (Independent Variable)
- **Temperature** (Dependent Variable)

> **Target Variable:** Temperature

---

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

---

## 📋 Project Workflow

1. Import required libraries
2. Load the dataset
3. Explore and preprocess the data
4. Select input and target variables
5. Split the dataset into training and testing sets
6. Train a Simple Linear Regression model
7. Make predictions
8. Evaluate model performance
9. Visualize regression results
10. Draw conclusions

---

## 📊 Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

---

## 📈 Visualization

The project includes:
- Scatter plot of actual data
- Regression line
- Actual vs Predicted comparison
